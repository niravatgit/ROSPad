Learn ROS2 in the Browser

ROSpad is a browser-based ROS2 IDE with a live 3D simulator. No installation required — write Python nodes, launch packages, and see your robot move, all from a browser tab.

🐍 Python nodes 🤖 Live 3D sim 📦 ROS2 packages ⚡ Launch files
Getting Started
🔐
Logging In Beginner ›

Open ROSpad in your browser. You will see a login screen.

  • Enter the username and password given by your instructor.
  • New users can click Register to create an account.
  • Once logged in, you land on the main IDE.
ℹ️ Each student has a private workspace. Your files and packages are isolated from other students.
🗺️
The IDE Layout Beginner ›
📁
File Explorer (left)
Your workspace packages. Click a folder to expand it. Click a file to open it in the editor. System Packages shows read-only ROS2 packages.
📝
Editor (centre)
Monaco editor (same as VS Code). Supports Python, XML, YAML. Files auto-save as you type.
🖥️
Terminal (bottom)
Type ROS2 commands: ros2 topic list, ros2 launch …, colcon build. Open multiple terminal sessions with +.
🤖
3D Sim (right)
Live 3D robot simulation. Loads the robot when you launch a package. Use mouse to orbit/zoom. Press WASD to drive the DiffBot.
📡
Topics Panel
Click the Topics tab (top of right panel) to see live topic data from running nodes.
🎛️
Toolbar (top)
▶ Run a .py file   ⚡ Launch a launch file   ■ Stop running nodes
!Button state rules›
  • ▶ Run — enabled only when a .py file (non-launch) is open and no node is running.
  • ⚡ Launch — enabled only when a .launch.py file is open and no node is running.
  • ■ Stop — enabled only when a node is running. Stops all nodes across all terminal sessions.
Tutorial 1 — Talker / Listener
📢
Hello ROS2: Publish & Subscribe Beginner ›

The classic ROS2 demo: one node publishes messages, another subscribes. You'll create a Python package with two nodes and run them in separate terminal sessions.

1Create the package›

In the terminal, type:

$ros2 pkg create my_talker

This creates the directory src/my_talker/ with package.xml, setup.py, and a default node stub. You will see it appear in the file explorer.

💡You can also click + File in the toolbar and type the path manually, but using ros2 pkg create sets up all required files at once.
2Write the talker node›

In the file explorer, open src/my_talker/my_talker/my_node.py. Replace its contents with:

Python — talker.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class Talker(Node):
    def __init__(self):
        super().__init__('talker')
        self.pub   = self.create_publisher(String, '/chatter', 10)
        self.timer = self.create_timer(1.0, self.publish_msg)
        self.count = 0
        self.get_logger().info('Talker started!')

    def publish_msg(self):
        msg = String()
        msg.data = f'Hello ROS2! count={self.count}'
        self.pub.publish(msg)
        self.get_logger().info(f'Publishing: {msg.data}')
        self.count += 1


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(Talker())
    rclpy.shutdown()

Click ▶ Run. You should see "Talker started!" in the terminal, followed by publish messages every second.

3Write and run the listener›

Click + next to the terminal tabs to open a second terminal session. Then click + File and create src/my_talker/my_talker/listener.py:

Python — listener.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class Listener(Node):
    def __init__(self):
        super().__init__('listener')
        self.sub = self.create_subscription(
            String, '/chatter', self.on_msg, 10)
        self.get_logger().info('Listener ready — waiting for messages…')

    def on_msg(self, msg):
        self.get_logger().info(f'Heard: {msg.data}')


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(Listener())
    rclpy.shutdown()

Open listener.py in the editor, then click ▶ Run. You will see the messages arriving from the talker.

💡To stop, click ■ Stop. This stops all running nodes.
4Inspect the topic in the terminal›

While the talker is running, try these in the terminal:

$ros2 topic list
$ros2 topic echo /chatter
$ros2 topic hz /chatter
ℹ️You can also open the Topics tab in the right panel to see a live dashboard of all active topics.
5Create a launch file (optional)›

Add both nodes to a launch file so they start together. Create src/my_talker/launch/demo.launch.py:

Python — demo.launch.py
from launch import LaunchDescription
from launch_ros.actions import Node


def generate_launch_description():
    return LaunchDescription([
        Node(package='my_talker', executable='my_node', name='talker'),
        Node(package='my_talker', executable='listener', name='listener'),
    ])

Also add the listener entry point to setup.py. Open it and add 'listener = my_talker.listener:main' to console_scripts. Then open demo.launch.py and click ⚡ Launch.

Tutorial 2 — Turtlesim
🐢
Draw with a Turtle Beginner ›

Write a node that moves a turtle through a 2D canvas by publishing its pose. The sim automatically switches to turtle view when messages arrive on /turtle1/pose.

ℹ️The turtle canvas is an 11×11 unit grid (0–11 on both axes). The turtle starts at (5.5, 5.5). Publish a sequence of poses to trace a path.
1Create the package›
$ros2 pkg create turtle_demo
2Write the circle drawer›

Open src/turtle_demo/turtle_demo/my_node.py and replace with:

Python — turtle_circle.py
import math
import rclpy
from rclpy.node import Node


class TurtleCircle(Node):
    def __init__(self):
        super().__init__('turtle_circle')
        # Use raw rosBus to publish turtlesim pose
        import js
        self.bus = js.window.rosBus
        self.t   = 0.0
        self.timer = self.create_timer(0.05, self.step)
        self.get_logger().info('Turtle circle started!')

    def step(self):
        self.t += 0.05
        x     = 5.5 + 3.0 * math.cos(self.t)
        y     = 5.5 + 3.0 * math.sin(self.t)
        theta = self.t + math.pi / 2
        self.bus.publish(
            '/turtle1/pose', 'turtlesim/Pose',
            {'x': x, 'y': y, 'theta': theta,
             'linear_velocity': 1.0, 'angular_velocity': 1.0}
        )


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(TurtleCircle())
    rclpy.shutdown()

Click ▶ Run. The sim switches to the turtle canvas and draws a circle. Click ■ Stop when done.

3Try a spiral or square›

Change the step() method to draw a square:

Python — square path
    def step(self):
        self.t += 0.05
        side   = 4.0           # square side length
        period = self.t % (4 * side / 1.0)
        seg    = int(period / side)  # which side 0–3
        s      = period % side         # distance along side
        corners = [(2,2), (9,2), (9,9), (2,9)]
        cx0, cy0 = corners[seg]
        cx1, cy1 = corners[(seg+1) % 4]
        t = s / side
        x = cx0 + t * (cx1 - cx0)
        y = cy0 + t * (cy1 - cy0)
        self.bus.publish('/turtle1/pose', 'turtlesim/Pose',
                         {'x': x, 'y': y, 'theta': 0.0})

Tutorial 3 — Differential Drive Robot
🚗
Launch and Drive the DiffBot Intermediate ›

The DiffBot is a two-wheeled differential drive robot. Launch its package and the 3D sim loads the robot automatically. Then write a controller node to drive it.

1Launch the DiffBot›

In the System Packages section of the file explorer, expand diffbot_description → launch and click diffbot_bringup.launch.py. The file opens read-only. Click ⚡ Launch.

The 3D sim will show the DiffBot in a few seconds. The status bar at the bottom of the sim panel confirms: DiffBot.

💡You can also type this in the terminal: ros2 launch diffbot_description diffbot_bringup.launch.py
2Drive with keyboard (built-in)›

Click on the 3D viewport to give it focus, then use:

  • W — move forward
  • S — move backward
  • A — turn left
  • D — turn right

The robot publishes /cmd_vel and its odometry on /odom.

3Create a controller package›
$ros2 pkg create my_diffbot_ctrl

Open src/my_diffbot_ctrl/my_diffbot_ctrl/my_node.py and replace with a simple forward-move controller:

Python — simple_drive.py
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist


class DriveForward(Node):
    def __init__(self):
        super().__init__('drive_forward')
        self.pub   = self.create_publisher(Twist, '/cmd_vel', 10)
        self.timer = self.create_timer(0.1, self.drive)
        self.get_logger().info('Driving forward at 0.3 m/s')

    def drive(self):
        msg = Twist()
        msg.linear.x  = 0.3   # m/s forward
        msg.angular.z = 0.0   # no turning
        self.pub.publish(msg)


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(DriveForward())
    rclpy.shutdown()

Keep the launch file running. In a new terminal session, open the controller file and click ▶ Run. The robot moves forward. Click ■ Stop to halt.

4Read odometry›

Create src/my_diffbot_ctrl/my_diffbot_ctrl/odom_reader.py:

Python — odom_reader.py
import rclpy
from rclpy.node import Node
from nav_msgs.msg import Odometry


class OdomReader(Node):
    def __init__(self):
        super().__init__('odom_reader')
        self.create_subscription(Odometry, '/odom', self.cb, 10)

    def cb(self, msg):
        x = msg.pose.pose.position.x
        y = msg.pose.pose.position.y
        self.get_logger().info(f'Position: x={x:.3f}  y={y:.3f}')


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(OdomReader())
    rclpy.shutdown()

Tutorial 4 — UR5 Robot Arm
🦾
Launch and Control the UR5 6-DOF Arm Advanced ›

The UR5 is a 6-joint industrial robot arm. Launch the description package to load it in the sim, then publish joint states to move each joint.

1Launch the UR5›

In the file explorer, expand System Packages → ur5_description → launch and click ur5_bringup.launch.py. Click ⚡ Launch.

The 3D sim loads the UR5 arm in its home position.

ℹ️The arm starts in a bent-elbow home pose: [0, −π/2, 0, −π/2, 0, 0]. This keeps it upright and away from singularities.
2Joint names and axes›
#Joint NameAxisRange
0shoulder_pan_jointZ (rotation)±360°
1shoulder_lift_jointY (lift)±360°
2elbow_jointY (elbow bend)±180°
3wrist_1_jointY (wrist tilt)±360°
4wrist_2_jointZ (wrist rotate)±360°
5wrist_3_jointY (tool spin)±360°
3Create a joint state publisher›
$ros2 pkg create my_ur5_ctrl

Open src/my_ur5_ctrl/my_ur5_ctrl/my_node.py and replace with:

Python — joint_publisher.py
import math
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState

JOINTS = [
    'shoulder_pan_joint', 'shoulder_lift_joint', 'elbow_joint',
    'wrist_1_joint',      'wrist_2_joint',       'wrist_3_joint',
]

# Edit these angles (radians) to move the arm
POSITIONS = [0.0, -1.57, 0.0, -1.57, 0.0, 0.0]


class JointPublisher(Node):
    def __init__(self):
        super().__init__('joint_publisher')
        self.pub   = self.create_publisher(JointState, '/joint_states', 10)
        self.timer = self.create_timer(0.05, self.publish)
        self.get_logger().info('Publishing joint states at 20 Hz')

    def publish(self):
        msg = JointState()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.name     = JOINTS
        msg.position = list(POSITIONS)
        msg.velocity = [0.0] * 6
        msg.effort   = [0.0] * 6
        self.pub.publish(msg)


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(JointPublisher())
    rclpy.shutdown()

Edit POSITIONS to set joint angles, then click ▶ Run.

💡Joint values are in radians. −1.57 ≈ −90°, 1.57 ≈ 90°. Positive elbow_joint bends the arm upward.
4Animate the arm with a sine wave›

Create src/my_ur5_ctrl/my_ur5_ctrl/sine_demo.py:

Python — sine_demo.py
import math, rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState

JOINTS = ['shoulder_pan_joint', 'shoulder_lift_joint',
          'elbow_joint', 'wrist_1_joint',
          'wrist_2_joint', 'wrist_3_joint']

AMP  = [0.8, 0.4, 0.6, 0.4, 0.5, 0.3]
FREQ = [0.3, 0.5, 0.4, 0.7, 0.6, 0.9]
OFF  = [0.0, -1.57, 0.0, -1.57, 0.0, 0.0]


class SineDemo(Node):
    def __init__(self):
        super().__init__('sine_demo')
        self.pub   = self.create_publisher(JointState, '/joint_states', 10)
        self.timer = self.create_timer(0.033, self.step)
        self.t = 0.0

    def step(self):
        self.t += 0.033
        pos = [OFF[i] + AMP[i] * math.sin(2*math.pi*FREQ[i]*self.t)
               for i in range(6)]
        msg = JointState()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.name = JOINTS; msg.position = pos
        msg.velocity = [0.0]*6; msg.effort = [0.0]*6
        self.pub.publish(msg)


def main(args=None):
    rclpy.init(args=args)
    rclpy.spin(SineDemo())
    rclpy.shutdown()

Open sine_demo.py and click ▶ Run. The arm dances through smooth sine-wave motion across all 6 joints.

Tips & Troubleshooting ›
?The sim panel is empty›

The sim starts empty. Launch a package (e.g. diffbot_bringup.launch.py or ur5_bringup.launch.py) to load a robot. The robot loads automatically when the launch file publishes /robot_description.

?▶ Run is greyed out›

Run is enabled only for .py files (not launch files, not URDF). Open a Python node file in the editor. Also check that no node is currently running (Stop first if needed).

?⚡ Launch is greyed out›

Launch is enabled only for .launch.py files. Open a launch file (from your workspace or from System Packages). Also stop any running nodes first.

?My node crashed / keeps restarting›

Click ■ Stop to terminate all nodes. Check the terminal for the error traceback. Python syntax errors and import errors are the most common causes.

?The arm/robot doesn't move after I run my node›

Make sure the launch file is still running (it must stay active to keep the robot in the sim). Check the terminal for errors. Verify your topic name matches exactly — ROS2 topic names are case-sensitive.

?I can't see a topic I just created›

Topics only appear when a node is publishing or subscribing. Run your node first, then check ros2 topic list in the terminal or look in the Topics panel.
